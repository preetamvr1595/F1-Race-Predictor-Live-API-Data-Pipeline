# Release v1.0.0 — F1 Race Predictor End-to-End ML Pipeline

## Highlights
- Integrated 75 years of historical Ergast data (1950-2024) with live Jolpica-F1 API (2025-2026).
- Built 3 high-accuracy Gradient Boosting models (Podium, Winner, Exact Position).
- Created interactive Streamlit web dashboard with real driver/team form tracking.
- Included full test suite, Docker deployment, and GitHub Actions CI pipelines.
